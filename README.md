# 高中语文课程标准知识库

> 《普通高中语文课程标准（2017年版2025年修订）》的知识库与检索工具。

## 功能

- 确定教学目标与学业质量水平的对应
- 判断课文或设计属于哪个学习任务群（18 个任务群全覆盖）
- 按课标要求设计情境任务与命题，把学业质量水平转成评价任务与评分量规
- 核查教学是否契合核心素养四方面与学业质量标准

## 来源与引用

依据《普通高中语文课程标准（2017年版2025年修订）》，中华人民共和国教育部制定。

本仓库收录正文内容用于教学研究，并标注每份文件的版本状态与来源级别。**2025 版正式文本请以教育部及人民教育出版社发布为准**；本仓库未附镜像地址。课程标准是国家机关制定的具有行政性质的规范性文件，依据《中华人民共和国著作权法》第五条，不适用著作权法保护。

## 使用建议

课标是所有教学设计、命题、评价的**上位依据**。涉及具体条目时，应到 `references/` 中核对原文，不凭记忆复述。

## 常见引用误区

- 说"学业质量分**五级**"——现行课标是**三级**（水平一／二／三）
- 说"水平**四**指向高考"——高考命题依据是**水平二**
- 沿用旧编号（2-3、4-2）——课标不按 X-N 编号，改用"水平二·审美"这类表述
- 把必修目标线定在**水平一**——水平一只是毕业线，必修应标水平二
- 写"**祖国语言文字**"——应为"国家通用语言文字"
- 说成"五大核心素养"——课标明确是**四个方面**
- 四个方面**并列教学**——课标以"语言建构与运用"为基础
- 把学业质量水平描述**直接当打分量表**——它是总体刻画，需转化
- 默写范围说成 72 篇——高考范围是 **60 篇**（72 篇减去选修 12 篇）

## 安装

```bash
git clone https://github.com/zhshy/gaozhong-yuwen-kebiao.git
```

将技能目录放入 WorkBuddy 的用户级技能目录：

- **Windows**：`C:\Users\<用户名>\.workbuddy\skills\`
- **macOS / Linux**：`~/.workbuddy/skills/`

重启 WorkBuddy 后生效。

## 什么是 Skill

Skill 是给 AI 助手加载的专业知识包：一个 `SKILL.md` 定义触发条件与工作流程，`references/` 存放按需加载的细节文件。加载后助手会按既定流程工作，而不是即兴发挥。

本仓库技能遵循 Agent Skills 规范：YAML frontmatter + Markdown 正文 + 渐进式披露的 references。
