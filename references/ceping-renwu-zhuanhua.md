# 学业质量水平 → 评价任务转化

**用途**：把课标"学业质量水平"的描述性文字，转成课堂上可用的**评价任务**与**分级量规**。
**原文出处**：`references/xueye-zhiliang.md`（水平一／二／三完整原文）。本文件是**转化方法**，不是原文。

**必须先记住的一条**：课标的水平描述是**学业成就表现的总体刻画**，不是可直接拿来打分的量表。从"水平描述"到"评价工具"中间有一段需要自己走的路——本文件就是这段路。

---

## 一、三级水平的含义与取用

现行课标的水平编号只有**水平一、水平二、水平三**，**不按"2-3"这类 X-N 方式编号**。每个水平下用四段话分述四个方面：

| 段序 | 素养方面 | 段内结构 | 读什么内容的测评 |
|---|---|---|---|
| 第一段 | 语言建构与运用 | 梳理与探究 + 表达与交流 | 积累、语感、语境理解、表达规范 |
| 第二段 | **思维发展与提升** | 处理文本信息 + 日常交流与表达 | 信息处理、逻辑、质疑、问题解决 |
| 第三段 | **审美鉴赏与创造** | 欣赏文学作品 + 文学体验活动 | 文学感受、**语言品味**、作品评论 |
| 第四段 | 文化传承与理解 | 学习语言文字作品 + 日常学习与生活 | 文化现象、传统文化、跨文化理解 |

**三级各自的定位（原文）**：

| 水平 | 定位 |
|---|---|
| 水平一 | 普通高中**毕业**应达到的要求 |
| **水平二** | 普通高校**招生考试命题的依据** ← **必修阶段的目标线** |
| 水平三 | 供在语文学习方面**有更高要求**的学校设计课程与测评工具 |

**使用要点**：

- 设计**阅读课检测**，主力看**第二段（思维）与第三段（审美）**，语言与文化两段择要涉及
- **不要四段全测**。一节课打四个方向的检测，就是把课拆碎了
- **必修阶段默认对标水平二**——水平一只是毕业线，对标水平一会把目标定低
- 教考衔接的难题，可用**水平三**的表述反推能力上限
- 引用时写"**水平二·审美**"这类表述，不要写旧编号

## 二、转化的三步法

### 第 1 步｜定位：本课教学点对应哪一段水平描述

从 `xueye-zhiliang.md` 中找出与本课教学点**语义对应**的那一段。

**例**：《故都的秋》教学点定为"体会作者如何用语言营造清、静、悲凉的氛围"。
- 对应 **水平二·审美**："能借助联想和想象丰富自己的感受和体验，**品味作品的语言和形象**，表达自己感受到的语言和形象之美……**能从不同角度对作品的形式作出自己的评论**"
- 而非水平一·审美（水平一只要求"整体感受作品的语言和形象，把握作品的内涵"，不涉及"从不同角度评论形式"）

**对照检查**：如果教学点是"品味语言"，却对标了只要求"整体感受"的水平一，说明**目标是往低处定了**。

### 第 2 步｜拆解：把描述性文字拆成可观测的行为

水平描述里的动词是原料，但要具体到**能在课堂上看到的行为**。

| 原文动词 | 可观测行为（举例） |
|---|---|
| 整体感受作品的语言和形象 | 能用自己的话说出读完的第一感受，并指出是哪些语句带来的 |
| 借助联想和想象丰富感受 | 能补出文本未写的画面或情境，且不背离原文逻辑 |
| 品味作品的语言和形象 | 能指出关键词语／句式／标点，并说明改动后的效果差异 |
| 能从不同角度对作品的形式作出自己的评论 | 能指出一处写法上的选择，并说明它为什么比另一种写法好 |
| 对文本的内容或形式提出疑问 | 能提出一个"此处不通／可疑"的具体问题，并说明疑点在哪 |
| 阐释作品的情感、形象、主题和思想内涵 | 能就一处具体内容，说清它如何支撑主题，并引原文为证 |

**关键要求**：拆出来的行为必须**能指回具体的字词句**。指不回去，就是还没拆到位。

### 第 3 步｜定级：写出 2–3 个档的表现描述

用三级水平之间的差距做参照，为同一任务写出分档标准。

**通用句式**：`能/不能 + 具体行为 + 依据/证据`

**课堂量规默认三档**：**未达水平一 / 水平一 / 水平二**。若课程面向更高要求，可把优秀档提到**水平三**。

**例（同一任务的三档）**——检测"能否对作品形式作出评价"：

| 档 | 表现描述 | 对应水平 |
|---|---|---|
| 未达水平一 | 只能说"写得好""很优美"，无法指出具体语言现象 | 未达水平一 |
| 水平一 | 能指出喜欢的语句，说明理由停留在内容层面（写的是什么） | 水平一 |
| **水平二** | 能指出语言或形式上的具体现象，并说出它带来的感受；能比较两种写法的差异 | **水平二** |
| 【拓展】水平三 | 能对写法选择作出评价并说明作者为什么这样写；能参照研究资料，联系多个作品比较异同 | 水平三 |

**注意**：中间档不必写齐三层。课堂量规通常三档够用，标注对应水平号即可。

## 三、命题任务的三类情境

课标规定以**真实、典型、具体的语文实践活动情境**为载体，并明确三类情境的内涵：

| 情境类型 | 内涵（原文要点） | 检测任务形态举例 |
|---|---|---|
| **个人体验情境** | 学生个体独自开展的语文实践活动 | 写一段自己的阅读感受；为文中人物写内心独白；尝试用另一种文体改写 |
| **社会生活情境** | 校内外具体的社会生活，强调语言交际活动的对象、目的和表述方式 | 为班级读书会写推荐语；围绕文本争议点写一段辩论稿；给校刊写一篇短评 |
| **学科认知情境** | 探究语文学科本体相关问题，发展学科认知能力 | 比较两篇文本的写法差异；梳理一类表达方式的运用规律；探究一个语言现象的成因 |

**自查（来自课标命题要求，本 skill 已收）**：

- [ ] 题目落在具体情境中，且能说出是哪一类
- [ ] 是"典型任务"（多样、综合、开放）而非碎片化知识点
- [ ] 指向能对应"阅读与鉴赏／表达与交流／梳理与探究"
- [ ] 对应学业质量哪一级水平，依据可明示
- [ ] 保留开放性、个性化的作答空间
- [ ] 避开了机械训练式的设问

## 四、常见错误（用这份参考时必须避开）

| 错误 | 后果 | 纠正 |
|---|---|---|
| **把水平描述直接当量表** | 打分时无可操作性，教师间判分差异极大 | 必须走第 2、3 步拆解与定级 |
| **一节课对标四段素养** | 检测碎片化，什么都测等于什么都没测 | 阅读课主测思维、审美两段，其余择要 |
| **必修对标水平一** | 目标定在毕业线，教考脱节 | 必修默认**水平二** |
| **标高到水平三** | 面向普通学情会"学生全员不达标" | 难度靠任务调节，不靠提水平号 |
| **沿用旧编号（2-3 / 4-2）** | 引用即错，课标已无此编号 | 改"水平二·审美"式表述 |
| **仍说"水平四指向高考"** | 高考依据已改为**水平二** | 见 `SKILL.md` 第六节 |
| **只测"结果"不测"过程"** | 文学文本被用客观题测"怎么说的" | 见 `wang-rongsheng-reading-design/references/detection-design.md` |
| **量规写"理解深刻""语言优美"** | 无法观测，无法反馈 | 每个档必须含可检验的证据要求 |
| **检测内容超出本课教学点** | 测了没教的东西 | 逐条对照教学点，多出的删掉 |

## 六、使用方式

| 你的需求 | 本文件能提供的 |
|---|---|
| 给某节课出检测题 | 三步法 + 情境三类的任务形态 |
| 做阅读评价量规 | 定级句式 + 量规模板 |
| 判断检测题是否合规 | 第三条的自查清单 + 第四条的错误表 |
| 确定该对标水平几 | 第一条的三级定位 + 第二条第 1 步的对照法 |
| 需要水平描述原文 | 查 `references/xueye-zhiliang.md`（原文），本文件只做转化 |

**引用规范**：凡引用水平描述原文，注明《普通高中语文课程标准（2017 年版 2025 年修订）》"六、学业质量"及所在水平与段序，并到 `xueye-zhiliang.md` 核对，不凭记忆复述。
