# 学业质量水平 → 评价任务转化

**用途**：把课标"学业质量水平"的描述性文字，转成课堂上可用的**评价任务**与**分级量规**。
**原文出处**：`references/xueye-zhiliang.md`（1-1 至 4-4 完整原文）。本文件是**转化方法**，不是原文。

**必须先记住的一条**：课标的水平描述是**学业成就表现的总体刻画**，不是可直接拿来打分的量表。从"水平描述"到"评价工具"中间有一段需要自己走的路——本文件就是这段路。

---

## 一、四类水平编号的含义

课标的水平编号形如 `2-3`：

- **首位数字 1–4** = 水平等级。**水平 2 是必修课程的合格要求**，水平 4 指向高考选拔。
- **次位数字 1–4** = 对应核心素养的四个方面：

| 次位 | 指向的素养方面 | 读什么内容的测评 |
|---|---|---|
| **-1** | 语言建构与运用 | 积累、语感、语境理解、表达规范 |
| **-2** | 思维发展与提升 | 信息处理、逻辑、质疑、问题解决 |
| **-3** | 审美鉴赏与创造 | 文学感受、语言品味、作品评论 |
| **-4** | 文化传承与理解 | 文化现象、传统文化、跨文化理解 |

**使用要点**：
- 设计**阅读课检测**，主力看 **-2 与 -3**（阅读课主要落思维与审美），-1 与 -4 择要涉及
- **不要四条全测**。一节课打四个方向的检测，就是把课拆碎了
- 高一必修阶段默认对标**水平 2**；教考衔接的难题可用**水平 3、4**的表述反推能力要求

## 二、转化的三步法

### 第 1 步｜定位：本课教学点对应哪一条水平描述

从 `xueye-zhiliang.md` 中找出与本课教学点**语义对应**的条目。

**例**：《故都的秋》教学点定为"体会作者如何用语言营造清、静、悲凉的氛围"。
- 对应 **2-3**："能整体感受作品的语言、形象和情感，展开合理的联想和想象；能对作品的内容和形式作出自己的评价"
- 而非 1-3（1-3 只要求"整体感受形象，把握思想观点和情感倾向"，不涉及"内容和形式"的评价）

**对照检查**：如果教学点是"品味语言"，却对标了只要求"整体感受"的 1-3，说明**目标是往低处定了**。

### 第 2 步｜拆解：把描述性文字拆成可观测的行为

水平描述里的动词是原料，但要具体到**能在课堂上看到的行为**。

| 原文动词 | 可观测行为（举例） |
|---|---|
| 整体感受语言、形象和情感 | 能用自己的话说出读完的第一感受，并指出是哪些语句带来的 |
| 展开合理的联想和想象 | 能补出文本未写的画面或情境，且不背离原文逻辑 |
| 对内容和形式作出自己的评价 | 能指出一处写法上的选择，并说明它为什么比另一种写法好 |
| 品味语言，感受语言的美 | 能指出关键词语/句式/标点，并说明改动后的效果差异 |
| 能就文本的内容和形式进行质疑 | 能提出一个"此处不通/可疑"的具体问题，并说明疑点在哪 |

**关键要求**：拆出来的行为必须**能指回具体的字词句**。指不回去，就是还没拆到位。

### 第 3 步｜定级：写出 2–3 个档的表现描述

用水平 1–4 之间的差距做参照，为同一任务写出分档标准。

**通用句式**：`能/不能 + 具体行为 + 依据/证据`

**例（同一任务的四档）**——检测"能否对作品形式作出评价"：

| 档 | 表现描述 |
|---|---|
| 未达水平 1 | 只能说"写得好""很优美"，无法指出具体语言现象 |
| 水平 1 | 能指出喜欢的语句，说明理由停留在内容层面（写的是什么） |
| **水平 2** | 能指出语言或形式上的具体现象，并说出它带来的感受；能比较两种写法的差异 |
| 水平 3 | 能对写法选择作出评价，说明作者为什么这样写；能联系其他作品比较 |
| 水平 4 | 能质疑写法选择，提出替代方案并论证；能对文本的阐释作出批判性反思 |

**注意**：中间档不必写齐五档。**课堂量规通常三档够用**（未达标 / 达标 / 优秀），标注对应水平号即可。

## 三、命题任务的三类情境（与课标命题建议直接对接）

课标规定"以具体情境为载体"，三类情境必须能对应上：

| 情境类型 | 检测任务形态举例 |
|---|---|
| **个人体验情境** | 写一段自己的阅读感受；为文中人物写内心独白；尝试用另一种文体改写 |
| **社会生活情境** | 为班级读书会写推荐语；围绕文本争议点写一段辩论稿；给校刊写一篇短评 |
| **学科认知情境** | 比较两篇文本的写法差异；梳理一类表达方式的运用规律；探究一个语言现象的成因 |

**自查（来自课标命题六原则，本 skill 已收）**：
- [ ] 题目落在具体情境中，且能说出是哪一类
- [ ] 是"典型任务"（多样、综合、开放）而非碎片化知识点
- [ ] 指向能对应"阅读与鉴赏 / 表达与交流 / 梳理与探究"
- [ ] 对应学业质量哪一级水平，依据可明示
- [ ] 保留开放性、个性化的作答空间

## 四、常见错误（用这份参考时必须避开）

| 错误 | 后果 | 纠正 |
|---|---|---|
| **把水平描述直接当量表** | 打分时无可操作性，教师间判分差异极大 | 必须走第 2、3 步拆解与定级 |
| **一节课对标四条素养** | 检测碎片化，什么都测等于什么都没测 | 阅读课主测 -2、-3，其余择要 |
| **水平定错档** | 高一必修对标水平 4，学生全员不达标 | 必修默认水平 2；难度靠任务调节，不靠提水平号 |
| **只测"结果"不测"过程"** | 文学文本被用客观题测"怎么说的" | 见 `wang-rongsheng-reading-design/references/detection-design.md` |
| **量规写"理解深刻""语言优美"** | 无法观测，无法反馈 | 每个档必须含可检验的证据要求 |
| **检测内容超出本课教学点** | 测了没教的东西 | 逐条对照教学点，多出的删掉 |

## 六、使用方式

| 你的需求 | 本文件能提供的 |
|---|---|
| 给某节课出检测题 | 三步法 + 情境三类的任务形态 |
| 做阅读评价量规 | 定级句式 + 量规模板 |
| 判断检测题是否合规 | 第三条的自查清单 + 第四条的错误表 |

| 需要水平描述原文 | 查 `references/xueye-zhiliang.md`（原文），本文件只做转化 |
